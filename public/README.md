# 西澳打工度假 · 查核工具

一個靜態單頁。給人在西澳（Perth 及周邊）的台灣人，在**付錢或答應之前**查清楚。
主要讀者是打工度假者；`/pr` 與 `/settle` 那兩段是給已經開始想「要不要留下來」的人用的。

非營利。沒有廣告、沒有推薦回饋、沒有合作仲介。

## 十一個區塊

## 這個站故意不做的事

這一段比功能清單重要。它是設計約束，不是免責聲明。

| 不做 | 為什麼 |
|---|---|
| **職缺表／房源表／任何「今日有效」清單** | 維運者一離開就變成幽靈刊登，害人白跑。看起來比 LINE 正式，所以傷害更大。**這種頁面不准上線，除非它能在 48 小時沒人更新時自動清空。** |
| **「Perth 一週菜錢大約 $XXX」這種生活費行情** | 同上——**行情會過期，而且不會有人發現它過期了**。`/cost` 的解法是把「金額」跟「判準」分開：**金額由使用者自己填**，站上只提供三種不會腐壞的東西——**法定算式**（ATO 稅級距）、**官方公告價**（Transperth 票價、Containers for Change 10¢）、**比例判斷**（房租佔稅前收入幾成、這筆錢要工作幾小時）。<br>**這是 `DATA.cost` 的硬規則，`test/cost.test.js` 有一條測試在擋**：`DATA.cost.save` 裡不准出現「每週…$數字」這種寫死的生活費金額。 |
| **指名的詐騙黑名單** | 西澳與北領地是全澳洲唯二沒有採納 2021 年誹謗法改革的司法管轄區——沒有「重大損害門檻」、沒有法定公共利益抗辯。公開指名的風險在這裡最高。改用去識別化的「手法」與「交易守則」。 |
| **留言板／表單／登入／資料庫** | 任何可寫入的東西都需要審核。審核需要每天有人在。這個站的維運預算是每天 5 分鐘。 |
| **LINE bot** | 推播按收訊人數計費，一則摘要進 500 人的群＝計 500 則。而且一個群只能有一個 bot，需要管理員同意。 |
| **猜「幾分會被邀請」** | 移民部的官方點數表**沒有及格線**（整頁搜 `65` 零命中）。網路上流傳的分數線來自各人的獲邀回報，會隨每一輪的申請池變動，寫上去就是製造一個沒有官方背書、又會過期、還會直接影響別人要不要花兩年去讀書的數字。`/pr` **只算分，不猜線**——跟 `/cost` 只給判準不給行情是同一條原則。`test/pr.test.js` 有一條測試在擋。 |
| **抄 WASMOL／GOL 的職業清單** | 同上——清單會改版，抄下來的那份會在沒有人發現的情況下變成錯的，而「我的職業在不在清單上」是整條路徑的第一個分岔。站上只寫**怎麼去查**與**清單以外的三個條件**（僱傭合約形式、ABN 排除、491 的例外）。 |
| **當移民代辦** | 站上不判斷任何人的個案。點數試算的結果會明寫「這是你自己宣稱的分數，不是移民部認可的」，超出表格範圍時給的是官方連結與 MARA 註冊代辦的查詢方式，不是建議。 |
| **成為最終權威** | 每個數字旁邊都有生效日和官方連結。跟官方不一樣時，以官方為準。 |

技術上也鎖死：純靜態單檔、沒有 build step、沒有相依套件、沒有 API、沒有 `<form>`。
**想加功能時會先撞到架構，這是故意的。**

## 改資料

只改 `public/index.html` 底部的 `DATA` 物件。每一條都有：

```js
{ t:"名稱", u:"https://…官方網址", as:"YYYY-MM-DD", v:true }
```

- `as` — 生效日或查證日。**一定要跟著改**，這是使用者判斷資料新不新鮮的唯一依據。
  ⚠️ **兩種意思共用一個欄位，所以「舊日期」不一定等於「過期」**：來源本身有生效日的
  （公報、Bulletin、判決、pay guide）填**它自己的生效日**，`2022-07-20` 是那份文件的日期，不是疏漏；
  只有沒有生效日的一般網頁才填**查證日**。看到舊日期先分清楚是哪一種再決定要不要重查。
- `v` — 是否真的打開**官方**頁面確認過。`false` 會在畫面上顯示「待核」標籤。
  **民間智庫、媒體、論壇一律是 `false`**，內容再對也一樣——`v` 標的是「有沒有官方背書」，不是「我信不信」。
  **寧可標待核，不要填一個看起來合理的數字。**

`DATA.asOf` 是全站的資料生效日，顯示在頁首。

## 部署

**已上線：https://wa-whv.pages.dev**（Cloudflare Pages，專案名 `wa-whv`）。

```bash
npx wrangler pages deploy ./public --project-name=wa-whv --branch=main
```

要在 Cloudflare Pages 上直接接 GitHub repo 自動部署的話：build command **留空**、
**output directory 設成 `public`**。

本機預覽：用瀏覽器直接開 `public/index.html` 就可以，不需要 server。
（短網址 `/scam` 只有在 Cloudflare Pages 上才會生效，本機請用 `index.html#scam`。）

要用自動化工具測的話，多數無頭瀏覽器**擋 `file:` 協定**，起一個本機 server 比較省事：

```bash
python -m http.server 8787 --bind 127.0.0.1 --directory public
```

### 部署後的驗收（不要只看 wrangler 說成功）

wrangler 回報成功只證明它上傳完了，不證明邊緣吐出來的是新版。**用外部通道核對**：

```bash
curl -s https://wa-whv.pages.dev/ | sha256sum
```

拿它跟 `sha256sum public/index.html` 對，一樣才算真的上線。另外抽驗兩件事：

### 🔴 2026-08-16 的稅額事故（改 `whmTaxCents()` 前先讀這段）

**`whmTaxCents()` 曾經對 $135,000 以上的所得課 100% 邊際稅率。**舊版兩條 return 的結尾都是
`+ Math.max(0, annualCents - b2)`——超過第二級距的部分被**原封不動當成稅加進去**，沒有乘任何稅率。

- **實際偏差**：`$40／小時 × 70 小時` → 年化 $145,600 → 舊版算出 $44,350，
  ATO 正確值是 `$33,750 + $10,600 × 0.37 = $37,672`，**一年多扣 $6,678**。
- **這不是罕見輸入**：唯一的護欄是 `hours > 80`，所以 **$32.45／小時 × 80 小時**就已經跨過去了。
- **為什麼沒被抓到**：當時的測試只斷言「稅不超過收入本身」。100% 邊際稅率**通過**那條斷言——
  一條永遠不會紅的斷言比沒有測試更糟，因為它會讓人以為這段測過了。
- **修法**：把兩張表的第三、四級距都真的實作出來（`DATA.cost.tax` 現在有
  `b3/r3/base3/r4/base4` 與外國居民表的 `unreg/unregBase3/unregBase4`），
  **不是**加一個 bail 把高收入擋掉——擋掉等於對一個合法且到得了的輸入拒絕作答。
- **回歸測試**：`cost.test.js` 現在從 $1,000 掃到 $260,000，兩張表都不准出現高於 45% 的邊際稅率，
  也不准出現「多賺反而少拿」。另外釘住四個端點值與「沒登記在任何收入下都不會比有登記划算」。

同一批一起修掉的還有三件，都寫進測試了：**(1)** 剪貼簿寫死「WHM 15%」，年收跨過 $45,000 之後
畫面顯示 21.9% 而貼進群組的那份說 15%——同一次計算兩個數字，而群組看到的是錯的那個。
**(2)** 存錢目標曾經印「用 N × **1.3** 週去抓比較接近現實」——**1.3 沒有任何出處**，卻被印成一個具體週數。
現在改成把算式交給使用者（除以他自己那一行的實際有工作週數比例），並明說「這個比例只有你自己問得到，站上不猜」。
**(3)** `#crate` 的 placeholder 原本在 markup 寫死 `33.05`（法定地板的第二份副本，明年七月會靜默過期），
現在由 `DATA.wage.casualMin` 在開檔時灌進去；`#crent`、`#cfood` 的數字 placeholder 直接刪掉——
**那是錨點，不是提示**。三件都有守門測試，且測試自帶 canary。

酒莊 MA000090 Grade 1）**合法低於全國最低工資**，而這兩格正好是集二簽人口最常被歸進去的。

- **WorkCover WA 的 7 天／14 天程序時限** — `workcover.wa.gov.au` 對 WebFetch 回 403（頁面與 PDF 都是）。
  站上已就這幾個天數寫明「未親自逐字確認，以官方頁為準」。**受傷資格那句與 1300 794 744 是從
  `wa.gov.au` 鏡像頁逐字確認過的**，只有天數待核。
- **`/cost` 剩兩筆，都卡在 bot 防護**（頁面回 challenge 或 403，拿不到原文逐字比對）：
  **AIHW 的 30/40 rule**（「收入後 40% 家戶、房租佔稅前收入 >30% 即住房壓力」的定義）、
  **REIWA 的 Perth 各區租金中位數**。
  ⚠️ 第一條是**試算機實際拿來判斷的判準**，不是背景說明——30% 這個門檻直接決定使用者看到 ✅ 還是 ⚠️。
  第二條站上**只放連結不抄數字**，所以它待核的代價小。
  （**ACCC 的 Unit Pricing Code 已於 2026-08-16 清掉旗標**：`WebFetch` 仍被擋，但換帶 UA 的 `curl`
  抓得到全文 HTML，逐字讀完適用範圍那一節。見下方「已知的錯誤來源」第一條——**清旗標的同時修正了門檻本身**。）
- **`/cost` 的降價標籤卡（`pending:true`，不是 `v:false`）** — 「生鮮熟食接近保存期限會貼降價標」這件事本身
  沒有官方頁可引，而**網路上流傳的「幾點幾分貼」全是個人經驗**。
  站上的處理方式是**刻意不給時間**，並在卡片裡寫明「給了就是編的」。
  **清這個旗標的正確方式是找到官方或連鎖總部的公開說明，不是去抄一個論壇上的時間。**

## 接手

沒有帳號、沒有資料庫、沒有金鑰、沒有月費。

**原始碼在 https://github.com/jason201385-commits/wa-whv-toolkit（MIT 授權）。**
fork 下來、改 `public/index.html` 底部的 `DATA`、丟到任何靜態託管（Cloudflare Pages、
Netlify、GitHub Pages 都行）就是你的了。

不想碰 git 也行：在瀏覽器按「另存新檔」把這個站存成一個 `.html` 檔，你手上就有完整的
原始碼了——所有事實都在檔案底部 `<script>` 的 `DATA` 物件裡。短網址要自己補一個
`_redirects`（規則在本檔「檔案」段）。

**接手的話第一件要改的是上面複核日曆裡的「誰」。**

原作者不保證持續維護。這是設計，不是託辭。
